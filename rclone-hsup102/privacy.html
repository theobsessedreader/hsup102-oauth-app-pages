Privacy Policy — Rclone - HSUP102

Effective date: October 26, 2026

Rclone - HSUP102 is a personal-use OAuth client created to authorize Rclone on the account holder's Ubuntu computer to access Google Drive. It is not a hosted service offered to the public.

Google user data accessed

After the account holder authorizes access through Google, Rclone may access file and folder names, metadata, and file contents in the authorized Google Drive. If full Google Drive access is granted, the authorization can also permit creating, modifying, moving, or deleting files. The account holder controls the actions they perform using Rclone.

How the data is used

Google Drive data is used only to provide file access and file-management operations requested by the account holder, including listing directories, opening or downloading files, and uploading or organizing files. The integration does not use Google user data for advertising, profiling, or AI model training.

Storage and sharing

Rclone stores configuration and authorization tokens locally on the account holder's device. Data retrieved from Google Drive may be saved or cached locally as part of the operations the account holder requests. This project does not operate a separate server to receive or store Google Drive content, and it does not sell or disclose Google user data to advertisers or unrelated third parties.

Google handles authentication and Drive storage under Google's own terms. Rclone itself is third-party open-source software. The informational pages on this website are hosted by GitHub Pages, which may process routine website-access information under GitHub's privacy practices. These pages do not ask for passwords or OAuth tokens.

Security, retention, and control

Access continues while the Google authorization remains valid. The account holder can revoke the app's access in their Google Account connections settings. Locally stored tokens, cached files, and downloads can be deleted separately from the device; revoking Google access does not automatically erase local copies.

Contact

For questions about this personal integration, contact the project owner through their GitHub profile. Do not post sensitive credentials or private file information in a public issue.

This notice describes the personal integration above. It should be updated if the application's permissions, storage, or data-handling practices change.
